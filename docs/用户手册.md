## 1. 环境要求

- 操作系统：Windows
- 编辑器：Visual Studio Code（安装 C/C++ 扩展，用于代码提示与一键编译）
- 编译器：g++（随 Dev-C++ 安装，位于 Dev-Cpp/MinGW64/bin 目录，由 VSCode 编译任务自动调用，无需手动配置）

## 2. 编译与运行

1. 使用 VSCode 打开项目文件夹
2. 按 Ctrl+Shift+B 执行编译任务，自动编译 src 目录下全部源文件，生成 ros.exe
3. 在 VSCode 终端中执行任务 run ros（或直接输入 .\ros.exe），运行程序查看输出

编译任务中已配置 -fexec-charset=GBK 参数，保证程序输出的中文在 Windows 控制台正常显示。

## 3. 运行说明

程序启动后依次输出：

1. 各节点初始化日志（[INFO] 级，节点注册成功）
2. 正常消息发布：RosCore 转发日志与各订阅者的接收日志（含时间戳）
3. 自定义消息类型演示：温湿度消息按"温度 25.5°C / 湿度 60%"格式转发
4. 动态增删节点演示：新订阅者加入后可收到消息，移除后不再收到
5. 四个异常场景：空节点名、重复节点注册、空消息发布、不存在话题转发，每个场景输出 [ERROR] 级错误信息
6. 统一关闭日志

异常场景的输出是预期行为，用于验证程序面对非法输入不会崩溃。所有 [INFO]/[WARN]/[ERROR] 日志在输出到控制台的同时，会追加写入项目根目录下的 ros_log.txt，可在程序运行后打开复查。

## 4. 异常说明

| 错误信息 | 含义 |
|----------|------|
| 节点创建失败：节点名不能为空 | 创建节点时使用了空名字 |
| 节点注册失败：节点名 "xxx" 已存在 | 同名节点重复注册 |
| 消息发布失败：消息内容不能为空 | 发布的消息内容为空 |
| 消息转发失败：话题 "xxx" 不存在 | 向没有订阅者登记的话题发送消息 |

## 5. 常见问题

- 输出中文乱码：确认编译参数包含 -fexec-charset=GBK
- 编译报"undefined reference to main"：检查 src 目录下是否只有一个 main.cpp，其余阶段的测试代码不要保留未注释的 main 函数
